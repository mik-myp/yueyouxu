## 阶段 3A：经期事实与日期冲突

已完成：

- 新增 `PeriodRepository`，统一原生 SQLite 与 Web 预览的经期列表、读取、保存和删除接口。
- 新增 `record-period` 用例，支持经期开始、结束和修正日期。
- 开始日期、结束日期统一校验为本地 `YYYY-MM-DD`；结束日期不能早于开始日期。
- 新经期不能与其他已有经期重叠；修改自身记录时允许保留原 ID。
- 结束操作只结束最近一个尚未结束且开始日不晚于结束日的经期。
- 今天页和记录页的经期按钮接入 Repository，不再只修改临时 UI 状态。
- 今天页保留短暂撤销操作：撤销开始会删除新经期，撤销结束会恢复开放经期。
- 初始化创建的第一条开放经期可直接结束，刷新后状态仍从本地事实恢复。

浏览器验收：

- 初始化完成后点击“月经结束”，刷新后按钮变为“月经来了”。
- 再次点击“月经来了”，刷新后按钮恢复“月经结束”。
- Web `localStorage` 中的 `periods` 会分别保存 `endDate` 和 `null`，没有依赖临时状态。
