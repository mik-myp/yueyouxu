# 产品简报

更新日期：2026-09-01

## 产品定位

Yueyouxu（工作名称）是一款专注于经期记录、周期预测和个人趋势分析的移动应用。产品不提供健康内容信息流、社区、电商或泛生活服务。

它的单一核心任务是：让用户快速、安心地记录每日状态，并清楚地区分事实记录、算法预测和可选 AI 解读。

## 已确认的产品原则

1. **美观但清醒**：延续美柚式温暖、柔和的视觉气质，但减少粉色堆叠、营销感和装饰性卡片。
2. **记录足够简单**：开始或结束经期应能一步完成；常用每日记录应在两步内完成。
3. **记录可分析**：每次记录都进入本地分析数据源；预测结果必须可追溯到算法版本和输入范围。
4. **本地优先**：核心功能无需登录或联网；AI、同步和备份都是显式可选能力。

## v0.1 范围

v0.1 只实现无需账户和网络即可完成的基础闭环：设置周期基础信息、记录经期和每日状态、查看日历、获得本地预测，并回顾简单趋势。

### 核心页面

- 首次设置：最近一次经期开始日期，以及可选的初始周期和经期参考值；不要求填写姓名、年龄或其他健康资料。
- 今天：当前周期状态、预测范围、快速记录入口和当天摘要。
- 记录：上方月历展示实际经期、预测经期和每日记录状态；下方展示所选日期的记录项目，点击项目从底部展开详细字段。
- 趋势：基础的周期长度、经期长度、规律程度和历史记录。
- 设置：预测设置、隐私与数据、应用信息三个独立入口；具体内容在对应详情页调整或查看。

### 首次初始化信息

首次打开 App 时进入初始化页面，完成最小可用设置后进入今天页。初始化只收集影响经期预测的必要信息：

- 最近一次经期开始日期：必填，用于建立第一条周期事实记录。
- 初始周期长度：选填，默认 28 天；仅在完整周期样本不足时作为参考值。
- 初始经期长度：选填，默认 5 天；仅在经期记录样本不足时作为参考值。
- 自动计算：默认开启；有足够完整记录后由本地算法逐步替代初始参考值。

初始化不收集姓名、年龄、身高体重、备孕状态、性生活、地理位置或联系方式。用户可以跳过可选参考值，之后在“设置 → 预测设置”中补充或修正。

底部主导航固定为 `今天`、`记录`、`趋势` 和 `设置`，可从任意主页面直接进入设置。详细布局参见 [UI 布局规范](./ui-layout.md)。

### v0.1 明确不做

- 健康内容信息流。
- 社区、评论、私信或用户关系。
- 电商和广告推荐。
- 备孕模式。
- 易孕期和排卵日预测。
- 暗色模式。
- AI 分析和 AI 服务配置。
- 账户、多设备同步和云备份。
- 通知提醒和数据导入/导出。
- 桌面小组件、HealthKit、Health Connect 和可穿戴设备接入。
- 用 AI 代替本地预测算法。
- 医疗诊断、处方或治疗建议。

## 核心交互目标

- “月经来了”和“月经结束”始终是首页最容易触达的动作。
- 用户完成一次常用记录的目标时间不超过 10 秒。
- 所有记录面板先编辑临时值；点击右上角确认后统一保存，取消、遮罩关闭或下滑关闭均放弃本次修改。
- 实际记录使用实心状态，预测使用低饱和或轮廓状态，两者不能只靠文字区分。
- 空状态直接引导记录，不使用内容推荐填充页面。

## UI 方向

### 视觉签名

首页使用“周期弧”作为唯一主要视觉：实际经期、今天和预测范围沿时间弧分布。其他页面保持安静、紧凑和可扫描，避免每个区块都成为装饰卡片。

### 初始色彩令牌

| 名称              | 色值      | 用途             |
| ----------------- | --------- | ---------------- |
| `periodActual`    | `#E83F70` | 已记录经期       |
| `periodAction`    | `#F2537E` | 主操作           |
| `periodPredicted` | `#FFD8E5` | 预测范围         |
| `symptom`         | `#8D76C9` | 症状和次要数据   |
| `positive`        | `#4AAE91` | 已完成、正常确认 |
| `background`      | `#FFF8FA` | 页面背景         |
| `textPrimary`     | `#3C2932` | 正文和关键数字   |
| `textMuted`       | `#8B7A82` | 辅助信息         |

这些色值是设计起点，不是最终品牌规范。v0.1 应通过真机截图验证浅色界面的对比度和色觉可辨识度；暗色模式在后续版本单独设计和验证。

## 需要后续确认

- 经期历史允许修改到何种粒度，以及修订记录是否需要展示。
- 后续提醒的类型，以及数据导出采用 JSON、CSV 或两种格式。
- 备注是否参与本地算法或 AI 分析，默认建议不参与。
