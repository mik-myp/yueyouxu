# 批次 1：可调整 UI 原型结果

完成日期：2026-09-01

状态：已完成

## 交付内容

- 建立面向浅色移动界面的 Restyle 颜色、间距、圆角和文字令牌。
- 使用 Lucide 图标实现统一的导航、记录类型和页面操作图标。
- 实现 `今天`、`记录`、`趋势` 三标签导航，并从今天页进入独立设置页。
- 今天页包含日期、开放式周期弧、经期主操作、快速记录入口和当日摘要。
- 记录页采用上方月历、下方统一记录列表的上下结构。
- 月历使用中文月份头与星期标题；实际经期为连续实色带，预测经期为描边色带。
- 记录详情使用底部面板，覆盖流量、痛感、症状、心情和备注五类字段。
- 趋势页展示周期长度折线、个人范围和历史经期列表。
- 设置页展示周期默认值、本地数据说明和清除数据入口的布局原型。
- Web 文档设置中文语言、页面标题和主内容语义。

## 原型交互

- 日期选择会更新所选日期，并根据模拟实际经期范围更新经期操作状态。
- 流量、痛感和心情为单选，选择后关闭面板。
- 症状为多选，选择时保持面板打开并立即更新页面值。
- 备注在点击完成后更新，并在再次打开时恢复当前内存草稿。
- 今天页经期操作提供短时撤销提示；撤销会恢复状态并立即隐藏提示。
- 所有状态只保存在组件内存中，刷新或重新载入后恢复初始模拟数据。

## 技术说明

- `@gorhom/bottom-sheet` 的 Web 文本输入在 React Native Web 0.86 下仍调用已不存在的焦点 API。Web 改用标准 `TextInput`，iOS 和 Android 保留 `BottomSheetTextInput`。
- Bottom Sheet 默认背景、内容和把手在 Web 上被错误暴露为 slider。原型使用无额外语义的自定义背景和把手，保留视觉与拖动能力。
- `react-native-calendars` 默认月份头在 Web 上同样暴露为不完整 slider，且星期标题为英文。项目已替换为可访问的中文自定义月份头。
