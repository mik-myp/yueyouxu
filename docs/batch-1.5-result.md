# 批次 1.5：Soft Companion 视觉验证结果

完成日期：2026-09-01

状态：代码实现与自动检查完成，待 iOS 与 Android 真机验收

分支：`batch/1.5-soft-companion-visual-validation`

## 结论

现有 Expo + React Native + Restyle 技术栈可以实现 `Sorbet + Cashmere + Soft Pouf` 的组合，不需要仅因视觉效果切换 WebView。

本批次只完成视觉验证范围，不代表已批准向全 App 推广。iPhone 与 Android 真机均通过后，才允许选择“通过”并进入推广；在此之前分支不合并到 `master`。

## 实现范围

- 记录页：温暖灰粉画布、柔和日历状态、连续实际经期色带、低饱和预测描边、统一记录列表和局部软触感图标底座。
- 症状记录面板：只对这一种面板应用 Soft Companion 标题、50% 高度和轻内陷多选状态；流量、痛感、心情和备注面板保持批次 1 样式。
- 底部导航：全宽原生底栏、自定义安全区、Phosphor 图标、Cashmere 选中底座和支持减少动态效果的轻微弹性反馈。
- 实验令牌：新增 `companion*` 颜色，不替换原主题基础颜色，避免今天页、趋势页和设置页内容被间接换肤。
- 图标边界：新增项目 `soft-icons` 入口，按具体图标路径导入 Phosphor；未执行全项目 Lucide 迁移。

## 视觉分工

- Sorbet 负责日历、经期与预测状态的柔和色彩。
- Cashmere 负责温暖底色、成年化信息结构与克制留白。
- Soft Pouf 只用于月历翻页按钮、记录图标底座、症状选项和导航选中态。
- 连续经期色带仍是记录页唯一的强视觉记忆点，没有增加角色插画、嵌套卡片或全局厚阴影。

## 检查结果

- `npm run typecheck`：通过。
- `npm run lint`：通过。
- `npm test`：3 个测试套件、4 个测试通过。
- `npm run format:check`：通过。
- `npx expo-doctor@latest`：21/21 检查通过。
- `npx expo export --platform all`：Android、iOS、Web 导出通过。
- Web WCAG 2 A/AA 自动审计：记录页和打开的症状面板均为 0 个确定违规。
- Expo Router 会把非活动标签页保留在 Web DOM 中，遮罩和隐藏页面仍有无法自动判定的对比度节点；当前可见界面已通过自动与截图复核。

## 验证中修正的问题

- 症状面板沿用 62% 高度时在标准屏出现过多空白，已单独调整为 50%，紧凑屏内容仍完整。
- 自定义标签缺少 `tablist` 父语义，已补齐并通过 ARIA 审计。
- 底栏莓红文字和已选症状的薰衣草文字最初低于 4.5:1，已收深语义颜色并通过 WCAG AA。
- 从 Phosphor 根入口导入会让 Metro 遍历整套图标，已改为按路径导入；最终 Android、iOS、Web 入口约为 6.7 MB、6.5 MB、4.8 MB。

## 数据与架构边界

- 继续使用批次 1 的固定模拟数据与组件内存状态。
- 未修改 `src/features`、SQLite、Drizzle、Repository、领域模型、预测算法或持久化逻辑。
- 未引入 WebView、Capacitor 或 shadcn 运行时代码。
- 未改造今天页、趋势页、设置页、首次设置或其他四种记录面板的内容视觉。

## 真机验收入口

需要至少一台 iPhone 和一台 Android 真机检查：

1. 安全区和系统字体缩放下，标题、日历、底栏与长中文文本不重叠。
2. 月历翻页按钮、记录图标底座和导航选中态的阴影不发灰、不模糊、不过度膨胀。
3. 症状面板可以拖动、点击遮罩关闭，Android 返回键行为正确。
4. 375 级别短屏能滚动到全部五项记录，底栏不遮挡最后一项。
5. 系统开启减少动态效果后，导航没有弹性位移但选中态仍可辨识。

真机完成后由用户明确选择：`通过`、`调整后复验` 或 `放弃该方向`。只有选择 `通过` 后才合并 `master` 并规划其余页面推广。
