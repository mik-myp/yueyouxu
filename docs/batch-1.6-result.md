# 批次 1.6：Soft Companion 全局视觉推广结果

完成日期：2026-09-01

状态：实现完成，待用户验收

分支：`batch/1.6-soft-companion-global-ui`

## 结论

批次 1.5 验证通过的 `Sorbet + Cashmere + Soft Pouf` 组合已推广到现有全部页面、共享组件和记录面板。Expo + React Native + Restyle 可以维持一致的 `Soft Companion` 视觉，不需要为了这一视觉方向切换到 WebView。

本批次只修改表现层和视觉文档。固定模拟数据、组件内存状态、记录字段和交互语义保持不变，未修改 `src/features`、SQLite、Drizzle、Repository、领域模型、预测算法或持久化代码。

## 全局视觉系统

- 70% 成熟清晰：接近白色的温暖画布、系统中文字体、开放式信息区、细分隔线和稳定的 8px 网格。
- 20% 柔软触感：按钮、图标底座、选择项和导航选中态使用连续圆角、浅描边、短阴影和局部内高光。
- 10% 克制反馈：按下、选择、面板出现和导航切换保留轻微反馈，并继续支持系统减少动态效果。
- Sorbet 莓果色只表达实际经期、预测和主要动作；Cashmere 负责背景与层级；薰衣草、鼠尾草和低饱和杏色分别辅助症状、心情和痛感语义。
- 全项目通用图标统一为 Phosphor 并按具体路径导入，移除 `lucide-react-native`，避免混用图标语言和打包整套图标。

## 页面与组件

- 今天页：开放式周期轨道成为唯一主视觉，清楚区分本次经期、下次预测和当前日期；经期操作与记录入口维持一步可达。
- 记录页：保留已通过的月历、日期摘要、连续经期色带和统一记录列表，仅收敛痛感语义色及全局主题一致性。
- 趋势页：使用单一周期趋势线、双指标范围带和历史列表，不采用仪表盘卡片阵列。
- 设置页：使用成熟的开放式分组列表；隐私说明使用鼠尾草语义，清除数据保持独立危险操作样式。
- 记录面板：流量、痛感、症状、心情和备注共用面板外壳，各自使用符合字段语义的颜色、图标与展开高度。
- 共享组件：页面画布、主要按钮、图标按钮、分区标题、趋势线和周期轨道统一到全局语义令牌。

## 交互与无障碍

- 流量、痛感和心情单选后自动收起；症状支持面板内多选；备注完成后保存并回写摘要。
- 月历翻页、日期选择、经期状态切换、底栏切换、设置进入与返回行为保持正常。
- 记录、趋势和设置页面的 Web WCAG 2 A/AA 自动审计均为 0 个违规；首页为 0 个确定违规、4 个需人工复核的对比度节点。
- 打开面板后，遮罩后的隐藏日历节点会被自动审计标记为无法判定；可见面板无确定违规，截图人工复核通过。
- 浏览器没有运行时错误；仅存在 React Native Web 依赖已知的 `pointerEvents` 弃用警告。

## 验收关注点

仍建议在至少一台 iPhone 和一台 Android 真机确认：

1. 周期轨道、按钮、图标底座与底栏选中态的阴影不发灰或过度膨胀。
2. 紧凑屏滚动、系统字体缩放、顶部与底部安全区无文字和控件重叠。
3. 五类底部面板的拖动、遮罩关闭、Android 返回键与备注键盘避让正常。
4. 系统开启减少动态效果后，导航状态仍能通过颜色、底座和图标粗细辨识。

用户验收后，批次分支再按既定流程非快进合并到 `master`；批次 2 在此视觉基线上实现数据基础与首次设置。
