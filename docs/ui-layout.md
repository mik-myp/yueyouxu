# UI 布局规范

更新日期：2026-09-01

状态：v0.1 已确认

## 布局原则

- 参考美柚记录页中“上方日历、下方记录”的有效结构，但不复制其品牌资源和完整业务布局。
- 日历负责提供日期上下文，记录列表负责展示所选日期的数据，两者在同一页面完成操作。
- 首页的周期弧是唯一主要视觉，其余页面依靠留白、分隔线和清晰层级组织信息，避免卡片堆叠。
- 粉色只表达经期和主要操作，不使用大面积高饱和粉色。
- 经期开始或结束一步完成，常用每日记录最多两步完成。

## 全局导航

底部使用三个主入口：

1. `今天`：展示当前周期状态、预测范围、周期弧和经期开始/结束操作。
2. `记录`：展示日历、所选日期摘要和每日记录项目。
3. `趋势`：展示基础周期趋势和历史经期。

设置通过页面右上角的设置图标进入。v0.1 不设置“我的”入口，因为没有账户、社区、会员或个人内容中心。

## 今天页

页面从上到下依次为：

1. 日期和设置入口。
2. 周期弧、当前周期阶段和预测范围。
3. 随状态变化的主要操作：`月经来了`、`记录今天`或`月经结束`。
4. 当天记录摘要。

经期开始和结束操作立即保存，并短暂提供“撤销”，不增加确认弹窗。

## 记录页

记录页采用固定的上下结构：上半部分为月历，下半部分为所选日期的记录列表。

```text
<      2026年9月      >
日  一  二  三  四  五  六

       月历区域

9月1日  今天  经期第1天
--------------------------------
经期状态          月经结束  >
流量              中量      >
痛感              轻微      >
症状              腰酸、乏力 >
心情              平静      >
备注              未记录    >
```

### 日历规则

- 实际经期使用实心或连续色带。
- 预测经期使用低饱和填充或轮廓。
- 今天和当前选中日期使用不同的形状标记。
- 有每日记录的日期显示小型状态点。
- 不显示易孕期、排卵期和排卵日。
- 切换日期时，下方标题、周期状态和记录摘要同步更新。

### 记录列表

记录项目使用一整块白色列表和细分隔线，不把每个项目放入独立卡片。每行包含图标、项目名称、当前摘要和进入详情的指示图标。

点击记录项目后，从底部展开该项目的详细字段：

- 流量、痛感使用较矮的单选面板。
- 心情使用中等高度的单选面板。
- 症状使用可滚动的多选面板。
- 备注面板随软键盘扩展，必要时接近全屏。
- 单选项点击后立即保存并收起。
- 多选项实时保存，关闭面板即可完成。
- 修改后短暂提供“撤销”。

## v0.1 记录字段

| 项目 | 详细字段 |
| --- | --- |
| 经期状态 | 标记开始、标记结束、修正日期 |
| 流量 | 点滴、少量、中量、多量 |
| 痛感 | 无、轻微、中等、严重 |
| 症状 | 腰酸、腹胀、头痛、乏力、乳房胀痛 |
| 心情 | 平静、愉快、低落、焦虑、烦躁 |
| 备注 | 简短自由文本 |

v0.1 不记录性生活、避孕方式、体重、白带、体温、经血颜色和精确时间。这些字段不进入首版数据模型和界面。

## 趋势页

趋势页只展示最近周期长度、经期长度、周期波动范围和历史经期列表。每个图表只回答一个问题；数据不足时明确说明还需要多少个完整周期，不展示无意义的占位图。

## 视觉约束

- 页面采用浅色冷白背景，粉色用于实际经期、预测范围和主要操作。
- 日历本身不放入装饰卡片；记录列表使用统一白色内容区。
- 选中状态同时使用颜色、形状或描边表达，不能只依赖颜色。
- 常规页面左右间距建议为 `20px`，布局采用 `8px` 基础网格。
- 常规内容容器圆角不超过 `8px`；底部面板只在顶部使用适度圆角。
- 图标使用统一线性图标体系；只有流量等缺少通用语义图标的项目才设计简单领域图形。

## 不继承的美柚结构

- 经期、备孕、怀孕、育儿等顶部业务标签。
- 广告、会员分析、内容推荐和运营入口。
- 底部商城、消息、社区和账户入口。
- 大量圆形插画和每个区块独立成卡的视觉方式。
