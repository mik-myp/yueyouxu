# UI 布局规范

更新日期：2026-09-01

状态：v0.1 已确认

## 布局原则

- 参考美柚记录页中“上方日历、下方记录”的有效结构，但不复制其品牌资源和完整业务布局。
- 日历负责提供日期上下文，记录列表负责展示所选日期的数据，两者在同一页面完成操作。
- 首页的周期弧是唯一主要视觉，其余页面依靠留白、分隔线和清晰层级组织信息，避免卡片堆叠。
- 粉色只表达经期和主要操作，不使用大面积高饱和粉色。
- 经期开始或结束一步完成，常用每日记录最多两步完成。

## 全局导航

底部使用四个主入口：

1. `今天`：展示当前周期状态、预测范围、周期弧和经期开始/结束操作。
2. `记录`：展示日历、所选日期摘要和每日记录项目。
3. `趋势`：展示基础周期趋势和历史经期。
4. `设置`：提供周期默认值、隐私与数据、应用信息三个独立入口。

设置作为固定底部入口，可从任意主页面一步进入。v0.1 不设置“我的”入口，因为没有账户、社区、会员或个人内容中心。

## 今天页

页面从上到下依次为：

1. 单行完整日期。
2. 周期弧、当前周期阶段和预测范围。
3. 随状态变化的主要操作：`月经来了`、`记录今天`或`月经结束`。
4. 当天记录摘要。

经期开始和结束操作立即保存，并短暂提供“撤销”，不增加确认弹窗。

## 记录页

记录页采用固定的上下结构：上半部分为月历，下半部分为所选日期的记录列表。

```text
<      2026年9月      >
日  一  二  三  四  五  六

       月历区域

9月1日  今天  经期第1天
--------------------------------
经期状态          月经结束  >
流量              中量      >
痛感              轻微      >
症状              腰酸、乏力 >
心情              平静      >
备注              未记录    >
```

### 日历规则

- 实际经期使用实心或连续色带。
- 预测经期使用浅莓红填充和中等莓红轮廓，与实际经期保持明显强弱差异。
- 今天和当前选中日期使用不同的形状标记。
- 实际经期起点、预测经期起点和已有每日记录使用对应小图标；日历下方提供实际经期、预测经期、已记录和已选择图例。
- 日历支持左右滑动切换月份，并使用短方向淡入反馈；系统减少动态效果开启时取消动画。
- 不显示易孕期、排卵期和排卵日。
- 切换日期时，下方标题、周期状态和记录摘要同步更新。

### 记录列表

记录项目使用一整块白色列表和细分隔线，不把每个项目放入独立卡片。每行包含图标、项目名称、当前摘要和进入详情的指示图标。

点击记录项目后，从底部展开该项目的详细字段：

- 流量、痛感使用较矮的单选面板。
- 心情使用中等高度的单选面板。
- 症状使用可滚动的多选面板。
- 备注面板随软键盘扩展，必要时接近全屏。
- 所有面板左上角为取消、右上角为确认。
- 面板内的单选、多选和备注先写入临时值，只有点击确认才提交。
- 点击取消、遮罩关闭、手势下滑或系统返回均放弃本次修改。
- 修改后短暂提供“撤销”。

## v0.1 记录字段

| 项目     | 详细字段                         |
| -------- | -------------------------------- |
| 经期状态 | 标记开始、标记结束、修正日期     |
| 流量     | 点滴、少量、中量、多量           |
| 痛感     | 无、轻微、中等、严重             |
| 症状     | 腰酸、腹胀、头痛、乏力、乳房胀痛 |
| 心情     | 平静、愉快、低落、焦虑、烦躁     |
| 备注     | 简短自由文本                     |

v0.1 不记录性生活、避孕方式、体重、白带、体温、经血颜色和精确时间。这些字段不进入首版数据模型和界面。

## 趋势页

趋势页展示最近周期长度、经期长度、周期波动范围、本周期记录覆盖、基于现有记录的简短分析和历史经期列表。每个图表或分析区只回答一个问题；数据不足时明确说明样本范围，不展示无意义的占位图。

## 视觉约束

- 页面采用浅色冷白背景，粉色用于实际经期、预测范围和主要操作。
- 日历本身不放入装饰卡片；记录列表使用统一白色内容区。
- 选中状态同时使用颜色、形状或描边表达，不能只依赖颜色。
- 常规页面左右间距建议为 `20px`，布局采用 `8px` 基础网格。
- 常规内容容器圆角不超过 `8px`；底部面板只在顶部使用适度圆角。
- 图标使用统一线性图标体系；只有流量等缺少通用语义图标的项目才设计简单领域图形。

## Soft Companion 全局视觉规范

批次 1.5 验证通过后，现有全部页面统一采用 `Soft Companion`。它不是粉色主题，也不是把所有内容做成黏土卡片，而是一套面向成年女性、适合长期记录的轻柔操作语言。

### 视觉比例与职责

- `70% 成熟清晰`：系统中文字体、清楚的标题层级、开放式内容区、细分隔线和稳定留白。
- `20% 柔软触感`：Cashmere 图标底座、选项、翻页按钮和导航选中态使用连续圆角、浅描边和短阴影。
- `10% 克制反馈`：仅在按下、选择、面板出现和操作完成时使用轻微动画或状态变化；支持减少动态效果。

`Sorbet` 莓果色只表达实际经期、预测范围与主要动作；`Cashmere` 灰粉中性色组织背景和层级；薰衣草与鼠尾草分别辅助症状和心情语义。隐私说明使用鼠尾草色，危险操作保持独立的深莓红语义。

### 页面布局

```text
今天：单行日期 → 开放式周期轨道 → 主要操作 → 今日记录列表
记录：月历 → 日期摘要与经期操作 → 统一记录列表
趋势：周期主指标与趋势线 → 记录覆盖 → 个人范围 → 记录分析 → 历史列表
设置：周期设置 → 隐私与数据 → 关于与版本
```

- 首页周期轨道和连续经期色带是唯一强记忆点，其他区域不争夺视觉注意力。
- 趋势页不使用仪表盘式卡片阵列；图表、指标和历史记录各回答一个问题。
- 主页面不重复显示与底部导航同名的大标题和描述；内容从首个功能区开始。
- 设置首页只承担分类和跳转，不直接展开控件；周期默认值、隐私与数据、应用信息分别进入独立详情页。
- 周期详情页使用加减步进器调整常见周期长度与常见经期长度；批次 2 接入本地持久化。
- 隐私与数据页明确展示本地存储、AI 分析和云端同步状态，清除数据作为独立危险操作。
- 版本号只在关于页展示，设置首页不重复放置版本脚注。
- 底部面板使用统一外壳；流量、痛感、症状、心情和备注根据字段语义选择控件高度与强调色。

### 组件约束

- 页面背景接近白色，内容面使用轻微温差区分；不使用大面积渐变或装饰光斑。
- 常规信息容器圆角仍不超过 `8px`；`14–16px` 连续圆角仅用于按钮、图标底座、选择项和底部面板顶部。
- 柔软阴影只表示可按压或已选择，不作为普通分区装饰。
- 通用图标统一使用 Phosphor 的 regular/duotone 组合，尺寸以 18–23px 为主。
- 标题使用 600–700 字重，正文保持正常字重；所有统计数字使用 `tabular-nums`。

## 不继承的美柚结构

- 经期、备孕、怀孕、育儿等顶部业务标签。
- 广告、会员分析、内容推荐和运营入口。
- 底部商城、消息、社区和账户入口。
- 大量圆形插画和每个区块独立成卡的视觉方式。
