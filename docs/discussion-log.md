# 讨论记录

## 2026-09-01

### 已确认

- 产品聚焦经期记录、周期预测和趋势分析。
- 不包含健康内容、社区交流和电商。
- 技术路线为 Expo + React Native + Restyle。
- 产品要求美观但清醒、操作简单、本地优先。
- 每次记录都应成为本地算法的分析数据源。
- AI 分析可选，允许用户配置兼容 OpenAI 协议的 `baseURL` 和 API Key。
- v0.1 只实现首次设置、经期和基础每日记录、日历、本地预测、基础趋势及本地存储组成的离线基础闭环。
- v0.1 不包含备孕模式、易孕期或排卵预测、暗色模式、AI、账户同步、通知提醒、数据导入/导出、小组件和健康平台接入。
- AI 分析和服务配置推迟到离线基础功能稳定后的版本。
- 底部主导航采用 `今天`、`记录` 和 `趋势` 三个入口，设置从右上角进入。
- 记录页采用上方月历、下方所选日期记录列表的上下结构。
- 点击记录项目后从底部展开详细字段；单选立即保存，多选实时保存。
- v0.1 的记录项目确认为经期状态、流量、痛感、症状、心情和备注，具体选项记录在 UI 布局规范中。
- v0.1 分为工程基线、UI 原型、数据基础、记录闭环、预测、趋势与隐私、发布前加固七个批次。
- 每次只执行一个批次，当前批次验收完成后才进入下一批。
- 每批在开发前从 `master` 创建独立分支；完成后提交并推送分支，再以非快进方式合并和推送 `master`。
- 远端保留批次分支；已推送历史通过 `git revert` 回滚，不使用强制推送改写历史。
- 批次 0 采用 Expo SDK 57、React Native 0.86、React 19 和 TypeScript 6。
- v0.1 开发阶段使用 Expo Go；只有出现不受支持的原生模块时才切换 Development Build。
- SQL 层采用 Drizzle ORM，并通过 Repository 隔离页面、领域层和具体数据库操作。
- iOS 和 Android 是 v0.1 产品目标；SQLite Web 仍为 alpha，Web 仅作为开发辅助平台。

### 设计方向

- 参考美柚的柔和气质、粉色经期语义、日历高亮和图标化快速记录。
- 不复制美柚品牌资源，不继承其信息流、社区和营销型首页。
- 以“周期弧”作为首页主要视觉，其余界面保持克制和清晰。
- 日历不使用装饰卡片，记录区采用带分隔线的统一列表，不堆叠独立卡片。
- 实际记录、算法预测和 AI 解读必须具有不同视觉与文案身份。

### 架构提案

- 使用 SQLite 保存事实记录，分析结果采用可删除、可重算的版本化快照。
- 本地算法先完成预测和趋势，AI 只解释结构化结果。
- 用户 API Key 存入 SecureStore，不进入 SQLite 或日志。
- AI 调用前展示数据发送摘要，默认不发送备注原文。
- AI 功能的首个版本优先兼容 Chat Completions；Responses API 作为独立协议适配器评估。

### 待讨论

- 数据库是否需要应用级加密。
- 后续提醒类型和数据导入/导出格式。
- 后续版本的云同步和账户体系边界。
- 后续 AI 结果的持久化策略和免责声明表达。
