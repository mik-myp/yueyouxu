# v0.1 完整功能交付结果

分支：`batch/v0.1-complete`

## 已完成范围

### 首次设置与本地数据

- 首次进入只要求最近一次经期开始日，周期长度与经期长度提供可调整参考值。
- 支持自动计算与固定数值两种预测设置；AI 不参与日期计算。
- 原生端使用 SQLite，Web 预览使用 `localStorage`；刷新或重启后恢复初始化、经期、每日记录和设置。
- 清除全部数据具有二次确认，完成后删除事实与派生数据并返回首次设置。

### 经期与每日记录

- 支持经期开始、结束、撤销、修正开始日、修正结束日和删除。
- 禁止未来日期、结束早于开始、不同经期重叠及修正不存在的记录。
- 修正和删除先选择操作，只有点击右上角“确认”才写入数据；取消、遮罩关闭和下滑均不修改。
- 支持流量、痛感、症状、心情和最多 200 字备注；每日记录面板同样采用取消/确认语义。
- 空白每日记录不会保留“已记录”标记；日历状态、首页摘要和记录详情均来自真实 Repository 数据。

### 预测、首页与趋势

- 根据经期开始日间隔计算周期；自动模式使用中位数，样本不足回退用户参考值，固定模式严格使用设置值。
- 根据样本数量与波动输出最早、中心、最晚日期和低/中/高置信等级，不调用 AI，也不表达医疗结论。
- 首页周期弧、当前周期天数和预测范围使用真实计算结果。
- 趋势页展示平均周期、个人范围、周期波动、平均经期、本周期记录覆盖、记录积累和完整历史列表。
- 趋势折线由真实周期间隔生成，不再使用固定示意数据。

## 交互与视觉验收

- `Soft Companion` 视觉已覆盖今天、记录、趋势、设置、首次设置、详情页和全部底部面板。
- 390 × 844 Web 移动视口完成首次设置、记录、经期修正、趋势、设置和清除数据全流程检查。
- 初始化日历使用自定义日期单元与月份头，避免第三方默认 ARIA 角色错误。
