# Yueyouxu

一款使用 Expo、React Native、TypeScript 和 Restyle 开发的本地优先经期记录应用。

项目目前处于 v0.1 分批开发阶段。产品范围、UI 规范、架构和开发流程参见 [docs](./docs/README.md)。

## 本地开发

```sh
npm install
npm start
```

在 Expo CLI 中选择 Expo Go、iOS 模拟器、Android 模拟器或 Web。

## 质量检查

```sh
npm run typecheck
npm run lint
npm test
npm run format:check
```
